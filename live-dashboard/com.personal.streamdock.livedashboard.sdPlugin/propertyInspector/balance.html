Step 2

Tracks

Target minus Reference produces the signed difference. Freeze is configured separately for each selected track.
Step 3

Measurement

Live follows the current signal. Peak compares the peak values. Meter mode always uses peaks.
Step 4

Display mode

Number shows the signed difference and both dB values. Meters shows two peak bars. Status gives a quick BAD / EDGE / OK result.
