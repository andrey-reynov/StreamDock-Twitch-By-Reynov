StreamDock Twitch Live Dashboard

This guide is bundled with the plugin, so it remains available before the GitHub repository is published.

Step 1 — Add Dashboard

First drag Dashboard setup onto one normal LCD key. Select that action whenever you need to connect, disconnect, diagnose, or edit Twitch/OBS. It is the only action with the shared setup wizard.

Then drag Viewers, Chat messages, and Start / Stop stream onto normal LCD keys. The HSV293-S Info Board consists of three separate non-pressable Information slots; use Viewers, Chat, and passive OBS Status there. Keep Start / Stop on a pressable key.

Other actions intentionally have no connection form. Before setup they display SETUP / USE SETUP; when ready, each action shows only its own metric or control state.

Step 3 — Connect OBS

  1. In OBS open Tools → WebSocket Server Settings.
  2. Enable Enable WebSocket server. The default server port is 4455.
  3. Keep authentication enabled and copy the generated server password.
  4. In StreamDock use URL ws://127.0.0.1:4455, paste the password, and click Save & test OBS.

OBS READY confirms the connection and collapses the step. OBS AUTH means the password is missing or incorrect. OBS OFFLINE means OBS is closed, WebSocket is disabled, or the URL/port is wrong.

Optional OBS analytics

All of these read-only actions work on both normal keys and Info Board slots:

  • Stream bitrate — estimated kbps calculated from OBS output-byte counters every two seconds.
  • Stream time — OBS stream output duration.
  • Recording time — OBS recording output duration.
  • OBS health — OBS CPU usage, active FPS, and skipped output frames percentage.

GPU usage is not displayed. OBS WebSocket 5.x does not expose a reliable GPU-usage field. Showing a Windows-wide GPU number would be misleading because it would not identify OBS encoder/render load consistently.

Recording, audio, timer, and markers

  • Start / Stop recording controls OBS recording. OBS Status shows REC or LIVE+REC when appropriate.
  • Audio — Track uses one selected OBS input and offers Live + Peak or absolute range Meter / Value / Status modes.
  • Audio — Compare compares Target with Reference using Live or Peak values and can display a signed number, two peak meters, or status. Freeze is configured beside each track.
  • Reset all audio peaks clears every frozen peak at once after you adjust the mixer.
  • Twitch Account displays the connected account avatar and a green status dot.
  • Countdown Timer accepts hours, minutes, and seconds. Press to start/pause/resume; after zero it continues in red with a minus sign.
  • Moment Marker creates a Twitch VOD marker while live and an OBS recording chapter while recording. Its optional description is limited to 140 characters.

Moment Marker adds the Twitch channel:manage:broadcast permission. If Twitch was connected before v0.6, open Dashboard setup, disconnect Twitch, and connect it again once.

Quick test

  • Send a Twitch chat message; Chat should increase immediately.
  • Test viewers with another account/device and wait one or two minutes. Twitch generally does not count the broadcaster.
  • Test OBS Start / Stop with a safe scene before a real stream.
